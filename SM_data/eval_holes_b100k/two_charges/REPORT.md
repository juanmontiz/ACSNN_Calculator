# Two-charge exclusion: error analysis

Generated by `MODEL_SET=b100k python3 evaluate_two_charges.py`. Models: `best_statedict_gauss_128_hole_aab_b100k.pth`
for every pair of distinct charges {a, b}, a < b (the name is padded with the lower charge). Architecture `FlexibleNN`:
2 hidden layers × 128, Gaussian activation; inputs `[Z_ion, log10 E, one-hot(Theory_ID)]`; output `log10 σ`; target H.
Each model was trained for 100 000 epochs on CDW-EIS and CTMC data of the remaining 7 charges.

## Design

- **36 models = 36 pairs**, one model per pair.
- **72 cases** = (pair, evaluated excluded charge). Each case is evaluated on the 57 reference points of that charge
  (37 CDW-EIS + 20 CTMC).
- **Valid points.** Unless stated otherwise, metrics exclude CDW-EIS points with E < 50 keV/u (53 points left per case).
  There CDW-EIS falls to ~1e-28 cm², outside its validity range, and those points dominate linear errors. The
  `*_all_points.csv` tables include them.
- **Metrics.** All training-script metrics (MAE, RMSE, MBE, MRE, MaxAE, MaxRE on log10 σ) plus linear relative errors in σ
  (mean, median, P90, max, fraction of points below 5 % and 10 %).
- **Baseline.** The single-charge model `zzz` for the same evaluated charge; degradation = MAE(two-charge) / MAE(single).

### Classification with respect to the charge

| Level | Classes | Rule |
|---|---|---|
| Case (evaluated charge) | interpolation **isolated** | min(train) < z < max(train), and both z−1 and z+1 are training charges |
| | interpolation **adjacent** | inside the training range, but the partner is z ± 1 (local gap of two missing charges) |
| | extrapolation **d = 1** | outside the training range, nearest training charge at distance 1 |
| | extrapolation **d = 2** | outside the training range, nearest training charge at distance 2 (only Z = 1 in (1,2) and Z = 9 in (8,9)) |
| Pair (model) | interpolation / mixed / extrapolation | both charges interpolated / one each / both extrapolated |

Pair classes: 21 interpolation pairs, 12 mixed, 3 extrapolation: (1,2), (8,9), (1,9). Case classes: 42 isolated,
12 adjacent, 16 extrapolation d = 1, 2 extrapolation d = 2.

| interp. adjacent | 12 | 0.020 | 0.030 | −0.004 | 3.1 % | 12.2 % | 85 % |
| extrap. d = 1 | 16 | 0.170 | 0.233 | +0.153 | 33.7 % | 133 % | 35 % |
| extrap. d = 2 | 2 | 0.610 | 0.793 | +0.580 | 296 % | 1500 % | 8 % |

By pair class: interpolation MAE 0.022 (median 3.0 %), mixed 0.100 (5.6 %), extrapolation 0.290 (39.8 %).

Distribution of the per-case MAE log10 (median [IQR]): isolated 0.0145 [0.0122–0.0293], adjacent 0.0149
[0.0124–0.0168], extrap. d = 1 0.119 [0.041–0.257], extrap. d = 2 0.61 [0.36–0.86].

**Statistical tests** (`statistical_tests.txt`):
- The case classes differ significantly (Kruskal–Wallis H = 32.7, p = 4e-7), and so do the pair classes (H = 14.4, p = 8e-4).
- Interpolation vs extrapolation: Mann–Whitney p = 1e-8 (median MAE 0.015 vs 0.149).
- **Isolated vs adjacent interpolation: no difference** (p = 0.94, medians 0.0145 vs 0.0149). Removing a neighbouring
  charge does not cost accuracy for two excluded charges.
- Extrapolation d = 1 vs d = 2: p = 0.33 (only 2 d = 2 cases).

## 3. Pair ranking (mean over both charges)

- **Best:** (5,8) MAE 0.011 / 1.6 %, (2,6) 0.012 / 2.3 %, (3,6) 0.012 / 1.5 %, (5,7), (6,7), (7,8) ≈ 0.013 / 1.4–2.3 %.
  These are as good as excluding a single interior charge.
- **Worst interpolation pairs:** (2,3) MAE 0.041 / 8.5 % and (3,4) 0.024 / 4.3 %. These involve the low-charge region,
  where σ changes fastest with Z.
- **Mixed pairs containing Z = 1:** MAE 0.13–0.27 for every partner; (1,3) is the worst at 0.274 / 59 %, (1,4) 0.192 / 45 %.
  The error comes almost entirely from Z = 1, while the partner charge stays accurate.
- **Mixed pairs containing Z = 9:** MAE 0.021–0.034 (median 2.6–5.7 %), with (2,9) at 0.032 / 5.7 % driven by Z = 2.
- **Extrapolation pairs:** (8,9) 0.076 / 11.5 % (acceptable), (1,9) 0.150 / 32 %, (1,2) **0.644 / 276 %** (worst).

Full table: `pairs.csv`.

## 4. Effect of the second excluded charge (vs single-charge baseline)

- Excluding a second charge degrades the error on a given charge only slightly: Wilcoxon paired test p = 0.05, median MAE
  ratio 1.16, and 65 % of the cases are worse than the single-charge model.
- The median degradation is 1.15 for isolated cases and 1.20 for adjacent cases. The distance to the partner does not
  correlate with the degradation for interior charges 3–8 (Spearman ρ = −0.17, p = 0.25).
- **Exceptions, Z = 1, 3 and 4:** most two-charge models predict these charges better than the single-charge models
  `111`, `333` and `444` (median ratios 0.69, 0.62 and 0.77). This is not evidence that removing more data helps. Each
  baseline comes from a single training run, so differences of this size should be read with caution.
- **Z = 2, 5, 7 and 9 degrade the most** (median ratio 1.4–1.6, worse in ≥ 88 % of the cases). For Z = 2 the degradation
  is much larger when Z = 1 is also removed (extrapolation, ratio 5.6).

## 5. Energy dependence and bias

| Case class | E < 50 keV/u (MAE / median) | 50–500 keV/u | ≥ 500 keV/u |
|---|---|---|---|
| interp. isolated | 0.046 / 8.3 % | 0.022 / 3.2 % | 0.016 / 1.9 % |
| interp. adjacent | 0.037 / 7.5 % | 0.020 / 3.9 % | 0.018 / 2.1 % |
| extrap. d = 1 | 0.188 / 32 % | 0.170 / 36 % | 0.167 / 30 % |
| extrap. d = 2 | 0.512 / 275 % | 0.629 / 379 % | 0.615 / 571 % |

- For interpolation, error is largest at low energy (steep rise of σ) and the bias is ≈ 0 at all energies.
- For extrapolation, the error stays roughly constant with energy and the bias is **positive**: σ is overestimated over
  the whole range (MBE +0.15 to +0.17 above 50 keV/u for d = 1). The error is a global shift of the curve, not a local
  shape defect (see `curves_selected_pairs.png`, `error_vs_energy_by_case_class.png`).
- CDW-EIS is reproduced better than CTMC in interpolation (isolated: median 1.8 % vs 4.7 %; adjacent: 2.5 % vs 4.0 %). In
  extrapolation both theories have similar errors (d = 1: 31 % vs 34 %), again consistent with a charge-scaling error
  rather than noise.

## 6. Conclusions

1. Excluding two charges keeps the network **accurate for interior interpolation** (charges 3–8): median errors of 1.5–3.6 %
   and MAE ≈ 0.011–0.021 in log10, only ~15 % worse than single-charge exclusion.
2. **Adjacent exclusions** (two consecutive missing charges) are as accurate as isolated ones (median 3.1 % vs 2.6 %).
3. **The low-Z edge is the critical region.** Z = 2 is the hardest interpolated charge (systematic underestimation,
   MBE ≈ −0.04 to −0.06), and Z = 1 cannot be extrapolated: σ is overestimated by a factor of ~2 (d = 1) to ~13
   (d = 2, pair (1,2)) at all energies.
4. **The high-Z edge is benign.** Extrapolating to Z = 9 keeps median errors at 6 % (d = 1) and 24 % (d = 2), with σ smooth
   and slowly varying in Z there.
